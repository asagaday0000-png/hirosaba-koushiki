🛠️ 使用可能クライアント・MOD

当サーバーでは、以下のクライアント・MODを使用できます。
記載されていないものは、 使用前に運営へ確認してください。

🖥️ 許可クライアント

Lunar Client
Badlion Client
Feather Client
LabyMod
その他、通常のMinecraftプレイを目的としたクライアント

🧩 許可MOD

⚡ 軽量化

Sodium / Lithium / FerriteCore / EntityCulling 等

🏗️ 建築

Litematica / Schematica 等

🎥 録画

Replay Mod 等

🌐 翻訳

翻訳・チャット翻訳MOD

📊 HUD

Keystrokes / CPS / FPS / Ping / 座標 / Armor Status 等

🔍 視認性

Zoom / 明るさ調整 等

🚫 禁止

以下の機能は、クライアント・MODを問わず禁止します。

X-Ray・透過
自動クリック・自動攻撃
自動採掘・自動建築・自動移動
プレイヤー等の位置を不正に取得・表示する機能
その他、通常のプレイでは得られない情報を取得する機能
ゲームバランスを不正に変更する機能
⚠️ 記載されていないクライアントやMODについては、 使用前に運営へ確認してください。
サーバーの公平性や安全性を損なう機能については、 許可されているクライアントに含まれていても 使用を禁止する場合があります。
